# Space Crystal Retrieval


## Project Option
Simple Browser Game


## Project Description
Space Crystal Rescue is a simple browser game where the player is tasked to collect the scattered energy crystals while avoiding moving alien drones all before the timer runs out. Every crystal collected increases the player’s score, but running into the enemy ends the game entirely. The experience will begin with a title screen and short instruction page explaining the controls and the objective. After pressing the Start Game button, the player will move through the game area using the keyboard to collect crystals while avoiding the alien drones/hazards. A score counter and timer will display at the top of the screen to help players watch and track their progress. If all crystals are collected before the time runs out, the player wins. If the time runs out or if an enemy gets you, the player will lose and has to restart from the beginning.


## Theme Interpretation
My project responds to the theme of Space by taking place in distant space. Players explore a celestial environment filled with stars, planets, space technology, and unknown/mysterious alien life. The goal is to collect the valuable energy crystals whilst avoiding the dangerous alien drone before time runs out. The setting emphasizes exploration, survival, and adventuring in outer space. 


## Intended User or Player
Teenagers and young adults (13-30) 


## User or Player Goal
The player’s goal is to collect all 30 energy crystals before time runs out while avoiding alien drones. Collecting all crystals results in a victory, while running out of time or encountering an enemy results in a game over

## JavaScript Features
Move the player using the arrow keys or WASD
Randomly generate energy crystal locations after each crystal is collected
Increase the score whenever a crystal is collected
Run a countdown timer that ends the game when it reaches zero 
Detect collision with enemy alien drones and trigger a game-over screen 
Restart the game by resetting the score, timer, and player position 


## Responsive Design
The Score, Timer, and Crystal Counter will stack vertically on smaller screens to improve readability 
The game area will resize to fit smaller displays while keeping gameplay visible
The Start, Restart, and Instructions buttons will stack vertically on mobile devices 
Font sizes and spacing will automatically adjust to prevent horizontal scrolling 


## User Testing
From testing, I found that users grasped the overall objective and controls, finding them easy to understand. One user was able to collect only 1/10 crystals, they easily used both WASD and Arrow Keys, and confirmed that the game restart button functioned correctly. It was also noted that the game’s simple design made it easy for new players to understand. The main confusing issue was the game’s difficulty. The tester felt the drones accelerated too quickly, making the game impossible to complete. 


## Revisions
Based on the peer testing and my own self-testing, I made several revisions to improve the gameplay, balance, and overall user experience. I adjusted the enemy movement and speed progression to make the game more fair and playable, replaced the original grid-based movement with smoother 360-degree movement, and moved the Game Over and Mission Complete messages to the center of the game area for better visibility.
